CarListings Scraper & Database

Overview

CarListings Scraper & Database is a Python project designed to scrape vehicle listings from Bama.ir and store the extracted data into a structured SQL database.
This tool enables automated collection and storage of automotive market data like brand, model, price, city and mileage for analysis, monitoring, or further development.

Features

Scrape car listings from Bama.ir

Extract detailed vehicle information

Store collected data into a SQL database

Organized, efficient, and scalable architecture

Easy to customize for different data fields or database types


Technologies Used

Python 3

json (for web scraping)

httpx (for HTTP requests)

MySQL (for create and write on database)


Getting Started

Prerequisites

Python 3.x installed

Access to a SQL database (or use SQLite locally)

Install required Python packages:

pip install -r requirements.txt


How to Run

1. Clone the repository:

git clone https://github.com/your-username/your-repository.git
cd your-repository


2. Configure database settings inside config.py


3. Run the scraper:

car data collector.py
